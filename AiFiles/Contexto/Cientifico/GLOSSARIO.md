# Glossário operacional

| Termo | Definição operacional |
|---|---|
| Sessão de estudo | Registro iniciado pela pessoa usuária ao estudar um recurso e encerrado pelo sistema ou pela própria pessoa usuária. |
| Sessão válida | Sessão concluída com duração mínima de 5 minutos, sem invalidação. |
| Tópico | Unidade de conteúdo usada para organizar recursos, avaliações e análises, como Loops. |
| Formato de conteúdo | Categoria do recurso: vídeo, PDF, texto, mapa mental, podcast, quiz ou exercício prático. |
| Tentativa de avaliação | Submissão concluída de uma avaliação objetiva associada a um tópico. |
| Nota normalizada | Pontuação entre 0 e 100 calculada no servidor a partir das respostas corretas e dos pesos. |
| Evidência de aprendizagem | Vínculo analítico entre uma sessão válida única e uma tentativa posterior compatível da mesma conta e tópico, dentro da janela temporal; não é uma chave direta entre os dois registros. |
| Exposição mista | Existência de duas ou mais sessões elegíveis antes da mesma tentativa; não é usada na comparação simples entre formatos. |
| Nível de evidência | Classificação da quantidade e consistência de observações: insuficiente, inicial, moderada ou forte. |
| Efetividade observada | Descrição de resultados posteriores associados a um formato no histórico disponível; não é prova causal. |
| Recomendação exploratória | Sugestão de formato ou recurso quando ainda não há evidência suficiente para priorizar uma alternativa. |
| Recomendação contextual | Sugestão oficial baseada em evidências da mesma conta, módulo, tópico e período, acompanhada de justificativa e limitação. |
| Interpretação assistida | Texto opcional produzido pela Gemini a partir de DTO sintético agregado de métricas oficiais. Pode apontar padrões observados, feedbacks, conselhos e perguntas de reflexão, mas não cria métricas, não prova causalidade e possui resposta local de contingência. |
