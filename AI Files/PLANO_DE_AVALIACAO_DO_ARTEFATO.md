# Plano de avaliação do artefato

## Avaliação técnica obrigatória

| Item | Evidência esperada |
|---|---|
| Compilação | `npm run compilar` concluído sem erro |
| Estilo e tipos | `npm run verificar-estilo` e `npm run verificar-tipos` concluídos sem erro |
| Regras analíticas | Testes unitários para sessão válida, exposição mista, nível de evidência e recomendação exploratória |
| Banco | `npm run banco:reiniciar` recria banco e seed |
| Segurança básica | Testes de autorização e validação no servidor a implementar |
| Cenário demonstrativo | Roteiro repetido a partir de banco reiniciado |

## Avaliação de compreensão e usabilidade — futura

Objetivo: verificar se participantes conseguem interpretar indicadores sem concluir que a plataforma define estilos fixos.

Tarefas sugeridas:

1. Encontrar a última nota em um tópico.
2. Identificar se há dados suficientes para uma conclusão contextual.
3. Explicar a justificativa de uma recomendação.
4. Identificar a diferença entre selo docente e recomendação algorítmica.
5. Professor identifica tópico com sinal de atenção sem interpretar como ranking.

Medidas possíveis: conclusão da tarefa, tempo, erros, explicação verbal, escala de clareza e utilidade percebida. A escolha do instrumento e a coleta dependem do protocolo institucional.

## Restrições de interpretação

- Uma avaliação de usabilidade não comprova eficácia pedagógica.
- Dados sintéticos não devem ser relatados como resultado de participantes.
- Resultado favorável deve ser acompanhado de limitações, amostra, contexto e método.
