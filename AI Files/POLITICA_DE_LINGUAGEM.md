# Política de linguagem científica e da interface

## Regra central

Toda mensagem deve descrever dados observados, contexto e incerteza. Não usar uma nota, uma sessão ou uma preferência como rótulo permanente do estudante.

## Frases permitidas

- “Até o momento, exercícios práticos foram seguidos por resultados mais altos neste tópico.”
- “Há duas observações válidas; a evidência ainda é inicial.”
- “Ainda não há dados suficientes para priorizar um formato. Experimente esta alternativa e reavalie.”
- “Este alerta indica uma oportunidade de conversa pedagógica.”
- “O recurso foi aprovado pelo professor.”

## Frases proibidas

- “Você aprende melhor por vídeo.”
- “Este formato fez você aprender.”
- “O aluno é fraco neste conteúdo.”
- “Este estudante tem estilo prático.”
- “O professor comprovou que o material funciona.”
- “O aluno precisa estudar mais”, sem apresentar contexto observável.

## Substituições obrigatórias

| Evitar | Usar |
|---|---|
| melhor formato | formato associado aos resultados mais altos observados |
| prova | evidência disponível / resultado observado |
| dificuldade do aluno | resultado recente abaixo do limiar definido, no tópico e período indicados |
| recomendação certa | sugestão para experimentar |
| perfil do aluno | histórico disponível do aluno |

## Componentes de toda recomendação

1. Tópico ao qual se refere.
2. Quantidade de evidências válidas.
3. Período ou histórico considerado quando a interface passar a exibi-lo.
4. Resultado observado, se houver.
5. Nível de evidência.
6. Limitação explícita.
7. Próxima ação opcional do estudante.
